# Components

Every component of Pantrix UI 0.1.0-alpha05, under the group of its page: its composable, the package it is imported from, what it is for, the words it is also known by, the names its automation tags start with, and the key of its page. A component is imported by its package and its name: `import com.pantrixui.components.elements.button.PantrixButton`. This file is written from the library's sources at every build.

Contents: Elements · Form · Date & Time · Containers · Navigation · Overlays · Data · Charts · Adaptive · Icons

## Elements

## Icons

`PantrixIcons`, in `com.pantrixui.foundation.icons`, has 35 icons, each drawn in one colour: `PantrixIcon(imageVector = PantrixIcons.Star, contentDescription = null)`. One marked "mirrored" is drawn the other way round in a language read from right to left. An icon the set does not have comes from the app's own resources.

- `Check`: Confirmation. Symmetrical in meaning, so it never mirrors.
- `Close`: Closing or dismissing: a dialog, a sheet, a chip.
- `ChevronDown`: What opens below: a select's or an accordion's chevron. Never mirrors.
- `ChevronForward`: Points along the reading direction, so it mirrors in RTL. Mirrored.
- `ChevronBack`: Points against the reading direction, so it mirrors in RTL: a pagination's previous page. Mirrored.
- `FirstPage`: Back to where a row of pages starts: `ChevronBack` against a bar, a pagination's first page. Mirrors in RTL. Mirrored.
- `LastPage`: On to where a row of pages ends: `ChevronForward` against a bar, a pagination's last page. Mirrors in RTL. Mirrored.
- `ArrowBack`: Back to the previous screen, as Android and the web draw it; mirrors in RTL. Mirrored.
- `ArrowForward`: On to what comes next, as `ArrowBack` returns: the arrow between a range's two ends. Mirrors in RTL. Mirrored.
- `Calendar`: A page of a calendar: a date picker's field. Never mirrors.
- `Clock`: A clock's face, its hands at the hour and a little past it: a time picker's field. A clock turns the same way in every language, so it never mirrors.
- `Refresh`: Doing it again: a three-quarter turn, clockwise from the right and around to its head at the top right. A turn to the right reads the same in every language, so it never mirrors.
- `ZoomOut`: Showing more: a lens with a minus in it, which widens a range. A lens is held the same way in every language, so it never mirrors.
- `ZoomIn`: Showing less: `ZoomOut`'s lens with a plus, which narrows the range. Never mirrors.
- `MoreHorizontal`: Something folded away: the pages a breadcrumb trail or a pagination leaves out. Never mirrors.
- `Minus`: Indeterminate or partly selected.
- `Menu`: The menu a drawer opens: three lines, the mark every platform uses for it.
- `Plus`: Add. `Minus`'s line with the upright it is missing.
- `Info`: Information: an "i" in a circle, its dot at the top, the mark `Error` turns upside down.
- `Success`: Success: a tick in a circle.
- `Warning`: Warning: an exclamation mark in a triangle, the one status icon with a different outline.
- `Error`: Error: an exclamation mark in a circle, its dot at the bottom.
- `Inbox`: A tray with a notch in its rim: an inbox.
- `Star`: A five-pointed star: something marked as a favourite.
- `Folder`: A folder.
- `Person`: A head and shoulders: a person, an account.
- `Search`: A lens and its handle: a search. A lens is held the same way in every language, so it never mirrors.
- `Download`: An arrow down onto a line: taking something out of the app as a file. Never mirrors.
- `Upload`: An arrow up from a line: taking a file into the app. Never mirrors.
- `File`: A sheet with its upper corner folded: a file. The fold is at the upper right in every language, as a page's is in a file manager, so it never mirrors.
- `Copy`: Two sheets, one behind the other: copying, of a code block or of a link. The sheet behind shows at the upper left in every language, so it never mirrors.
- `Eye`: An eye: showing what is hidden, the text of a secure text field. It is the same eye in every language.
- `EyeOff`: `Eye` with a line through it: hiding the text again. The eye stops short of the line on either side, so that the line is read as one drawn across the eye and not as part of it.
- `Pause`: Two upright bars: stopping what moves by itself for a while.
- `Play`: A triangle that points to the right: letting what was stopped move again. A player's button points the same way in every language, so it never mirrors.
